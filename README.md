.# 📊 Dashboard de Vendas - Análise de Desempenho no Excel

## 📌 Visão Geral do Projeto
Este projeto foi desenvolvido como parte de um desafio prático da DIO focado em análise e visualização de dados. O objetivo principal foi transformar dados brutos de vendas em um **Dashboard Interativo e Visual no Microsoft Excel**, proporcionando insights claros para tomada de decisão estratégica e acompanhamento de métricas de desempenho.

---

## 🎯 Objetivos do Dashboard
- **Consolidação de Dados:** Centralizar registros brutos de transações em uma estrutura organizada.
- **Análise Dinâmica:** Permitir a filtragem e segmentação de dados por períodos, categorias, produtos e regiões.
- **Visualização Eficaz:** Transformar números em gráficos e indicadores-chave (KPIs) de fácil compreensão visual.
- **Suporte à Tomada de Decisão:** Facilitar a identificação de produtos mais vendidos, faturamento total, ticket médio e oportunidades de melhoria.

---

## 🛠️ Tecnologias e Recursos Utilizados
- **Microsoft Excel**:
  - **Tabelas Dinâmicas (Pivot Tables):** Para sumarização ágil dos dados brutos.
  - **Gráficos Dinâmicos (Pivot Charts):** Visualização clara de faturamento, volume e proporções.
  - **Fórmulas e Funções:** `SOMA`, `MÉDIA`, `CONT.VALORES`, `SE` e formatações.
  - **Segmentação de Dados (Slicers):** Filtros visuais e interativos com um clique.
  - **Design e Layout:** Paleta de cores harmônica e disposição intuitiva dos KPIs.

---

## 📈 Principais Métricas & KPIs Analisados
1. **Faturamento Total (R$):** Valor total gerado pelas vendas.
2. **Quantidade Total de Itens Vendidos:** Volume de transações concluídas.
3. **Ticket Médio:** Valor médio por transação/venda.
4. **Vendas por Categoria / Produto:** Identificação dos carros-chefe de vendas.
5. **Evolução Temporal:** Desempenho e sazonalidade de vendas.

## 🚀 Como Visualizar
1. Baixe o arquivo `.xlsx` deste repositório (clique no arquivo e depois no ícone de download).
2. Abra o arquivo no **Microsoft Excel** (ou Google Planilhas).
3. Habilite a edição e o conteúdo interativo caso solicitado.
4. Utilize os botões de **Segmentação de Dados (Filtros)** para navegar e explorar os dados dinamicamente.
